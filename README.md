# UI Motion Library

A reusable set of six micro-interaction specifications for AI-assisted frontend development.

| # | Interaction | Chinese |
|---|---|---|
| 01 | Press & Spring Back | 按压回弹 |
| 02 | Elastic Toggle | 弹性开关 |
| 03 | Touch Ripple | 跟手波纹 |
| 04 | Like Burst | 点赞反馈 |
| 05 | Animated Checkbox | 复选框动画 |
| 06 | Magnetic Button | 磁吸按钮 |

See [SKILL.md](SKILL.md) for animation parameters, triggers, accessibility, and implementation notes.

This repository contains design specifications and AI-agent instructions, not executable components or animations. The source is a user-supplied prompt collection, organized and clarified for reuse.
